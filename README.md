# 🔮 Квантовый код личности

Нумерологический веб-калькулятор для расчёта кода личности по ФИО, дате рождения и имени.  
Проект построен на чистом JavaScript (ES Modules) и использует собственную базу данных значений чисел от 0 до 100.

**Демо:** [https://ValeriaZherditskaia.github.io/numerology-site/](https://ValeriaZherditskaia.github.io/numerology-site/)

---

## 📖 О проекте

Сайт позволяет:
- Рассчитать нумерологический код по **фамилии, имени и отчеству** (с детальным разбором программ, самовосприятия, окружения, кодов Земли, Денег и Миссии);
- Получить **код души по дате рождения** (с редукцией дня, месяца, года и итоговой миссии);
- Проанализировать **отдельное имя** – как видит себя человек и как его видят другие;
- (в разработке) анализ номера телефона.

Все числа от 0 до 100 имеют подробные описания в **7 контекстах**: ядро, личность, энергия, земля, деньги, миссия и тень.

---

## 🛠️ Технологии

- HTML5, CSS3 (адаптивная вёрстка, тёмная/светлая тема)
- Чистый JavaScript (ES Modules, без фреймворков)
- Кастомная база данных в формате JS-объектов
- Модульная архитектура: `calculator.js`, `helpers.js`, `database.js`, `renderer.js`, `ui.js`, `config.js`

## 🚀 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/numerology-site.git
   cd numerology-site
   ```

2. Запустите локальный сервер (выберите удобный способ):
   - **Python 3:** `python3 -m http.server 8000`
   - **Node.js:** `npx http-server -p 8080`
   - **VS Code:** расширение Live Server

3. Откройте в браузере: `http://localhost:8000` (или другой порт)

## 🎯 Особенности

- **Алгоритм «Код слова»**: удаление пар одинаковых цифр, затем редукция.
- **Множество показателей**: код, сумма кода, программы, самовосприятие, восприятие окружением, общая сумма, ПСК, РК, КТ, коды Земли, Денег и Миссии.
- **База данных с 7 контекстами** для каждого числа (0–100) и отдельная база для даты рождения (0–9).
- **Интерактивные карточки**: клик по любой цифре открывает модальное окно с полным описанием.
- **Навигация «Дорожная карта»** для быстрого перехода по разделам результатов.
- **Админ-панель** с возможностью редактировать описания чисел (сохраняется в `localStorage`).
- **Справочник** с поиском и фильтрацией по диапазонам.
- **Переключение тёмной/светлой темы** с сохранением в `localStorage`.
